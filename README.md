# ДТП Радар — промо-лендинг

Статический одностраничный сайт: чистый HTML + CSS + JS, без сборки и серверной логики.
Можно открыть `index.html` прямо в браузере или выложить на любой статический хостинг.

## Файлы

```
index.html      — вся страница (секции: hero, преимущество, как работает, демо,
                  тест 14 дней, для кого, отзывы, FAQ, CTA)
styles.css      — дизайн-система и анимации
main.js         — появление при скролле, счётчики, мобильное меню, липкая CTA
assets/
  logo-header.png — оптимизированная копия 800px (CTA/OG)
  logo-mark.png — марка (машинки + пин) для шапки и футера
  favicon.png   — иконка сайта (64×64, красный пин)
  og-image.jpg  — превью для мессенджеров и соцсетей (1024×541)
```

## Что заменить перед публикацией

1. **Ссылки на мессенджеры.** В `index.html` четыре ссылки-заглушки `href="#"` с комментарием
   «Ссылки-заглушки» — в hero, в финальном CTA и в модалке. Заменить `#` на реальные контакты
   MAX / Telegram / WhatsApp / VK.
2. **Отзывы и цифры.** Секция `#reviews` и JSON-LD с отзывами в `<head>` содержат шаблоны —
   заменить на реальные отзывы. То же с цифрами в hero-блоке выгоды и в hero__stats
   (10+ городов, 500+ уведомлений, 20–40% выездов).
3. **Open Graph.** В `index.html` `og:image` уже стоит на абсолютном адресе
   (`https://dmitriyvolkov0.github.io/dtp-radar-landing/assets/og-image.jpg`) —
   относительный путь (`assets/og-image.jpg`) валидаторы не принимают,
   из-за чего при отправке ссылки в мессенджер выдаётся «Image is invalid».
4. Если появится домен — добавить `<link rel="canonical">`.

## Деплой на GitHub Pages

**Вариант 1 — отдельный публичный репозиторий (рекомендуется):**

1. Создать публичный репозиторий, например `dtp-radar-landing`.
2. Скопировать содержимое этой папки в его корень (`index.html` должен лежать в корне).
3. Settings → Pages → Source: «Deploy from a branch» → ветка `main`, папка `/ (root)` → Save.
4. Сайт появится на `https://<username>.github.io/<repo>/`.

**Вариант 2 — из основного репозитория (если он публичный или есть GitHub Pro):**

1. Добавить папку в репозиторий.
2. Settings → Pages → Source: «GitHub Actions» и простой workflow, который
   деплоит только эту папку, либо ветка `gh-pages` с содержимым папки.

**Свой домен (опционально):** файл `CNAME` с доменом в корне + DNS-запись
`CNAME <username>.github.io` у регистратора.

## Особенности

- Весь вес — PNG + CSS/JS, внешних запросов нет (шрифты системные) → быстрая загрузка.
- Анимации: появление при скролле (IntersectionObserver), пульс точек ДТП,
  «вспышка» на демо-карте → выезд уведомления, счётчики. Всё отключается при
  `prefers-reduced-motion: reduce`.
- В оффер-блоке показана бета-цена «от 2 900 ₽ / мес за экипаж» и таймер до конца
  бета-набора (дедлайн — конец текущего месяца, считается в main.js).
  Цифры 24/100 и цена — примеры: замените на реальные перед публикацией.
